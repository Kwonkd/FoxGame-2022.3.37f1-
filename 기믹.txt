기믹 - 게임을 재미있게하는 요소들
        내가 생각하는 것 보다 더 사소한 요소들도 모두 기믹이다. 플랫포머 게임에서 발판을 배치하는 것 또한 기믹
         새로운 요소를 생각하고 만드려고 하지 않고 지금 구현된 프로그램으로 최대한 맵 구성해보기

1. 움직이는 발판 - 상승, 하강, 대기 상태
                     - 다른 조작 없이 자동으로 움직이는 발판
                     - 플레이어가 레버를 당겨서(E) 상호작용하여 움직이는 발판
                     - 발판이 상하로 연결되어 동시에 움직이는 발판

2. 아이템 - 젬 : 필드에 소수의 수량만 배치. 기믹으로 잘 숨겨서 맵의 탐험요소를 강하게 하는데 사용.
            - 체리 : 필드에 다수 배치. 플레이어를 안내하거나 플레이어가 맵에 배치된 기믹을 학습하는 유도장치로 사용

3. 리스포너 - 플레이어 오브젝트가 파괴되면 프리팹을 불러와 특정 위치에 재생성.

4. 적 - 독수리 : 공중에 배치되어 있음. 플레이어를 추격함.
       - 개구리 : 땅에서 뛰어올라 이동.
       - 두더지 : 앞만 보고 움직임.

5. 플레이어 - 이동 : 좌우 방향키로 이동
               - 점프 : 키보드 A. 2단점프 가능. 
               - 공격 : 키보드 D. 원거리 공격
               - 엎드리기 : 키보드 S.
